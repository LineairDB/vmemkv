# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.

Report via **GitHub Security Advisories** (private vulnerability reporting) on
the repository's Security tab. Include the affected version, a minimal
reproducer if possible, and the impact you see.

We will acknowledge receipt, assess the report, and coordinate a fix and
release. Please allow time for the fix before any public disclosure.
